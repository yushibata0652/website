01 / CONTEXT

THE ASSIGNMENT.

This was a University of Michigan machine learning course project focused on image classification. The assignment required building, training, and evaluating deep-learning models on a dog-breed dataset containing more than 8,800 images.

What the project tested

Image preprocessing, GPU-based training, transfer learning, convolutional neural networks, Vision Transformers, validation strategy, and model comparison using more than one evaluation metric.

04 / ARCHITECTURE

CNN VS. VIT.

CONVOLUTIONAL NEURAL NETWORK

Strong local visual structure.

CNNs use convolutional filters to learn local spatial patterns such as edges, textures, and progressively higher-level visual features. Their architecture gives them a useful inductive bias for images.

VISION TRANSFORMER

Attention across image patches.

A Vision Transformer breaks an image into patches and uses self-attention to model relationships across those patches. The comparison showed that architecture choice and available data can strongly affect performance.

05 / RESULTS

WHAT THE MODELS SHOWED.

8.8K+ Dog-breed images used across the project dataset.
96.7% Peak validation accuracy for the strongest target CNN run.
≈0.998 AUROC for the strongest target CNN evaluation.
06 / CHALLENGES

WHAT REQUIRED JUDGMENT.

GENERALIZATION

Training performance is not the goal.

I had to watch validation behavior and compare model performance outside the training set to understand whether the model was actually generalizing.

MODEL CHOICE

More complex is not automatically better.

The CNN and ViT behaved differently on the same task, reinforcing that model architecture should be chosen with the dataset and problem in mind.

07 / POST-MATCH

WHAT I LEARNED.

ARCHITECTURE

Match the model to the data.

Model families encode different assumptions about how useful structure should be learned.

METRICS

One number is rarely enough.

Accuracy and AUROC provide different views of model behavior, especially when evaluating classification systems.

PIPELINE

Training is only one stage.

Preprocessing, validation, evaluation, and comparison are just as important as defining the neural network itself.
